CLI rules

Same features, built so agents can use them

One shape for every commandHuman-readable in a terminal. --json prints a single result object on stdout; progress goes to stderr as one JSON event per line.
Never blocksNo prompts when there's no terminal. Anything only a person can do returns exit 3 with a next hint saying what to ask the user.
Points to filesResults give absolute PNG and bundle paths, so an agent can show them as Markdown images in T3.
Exit codes
0done, nothing changed1visual changes or a broken journey2error (bad config, app down)3needs a person (sign-in)
